# Architecture Decision Records

Los ADR registran decisiones que afectan compatibilidad, seguridad o estructura. Estados usados: `Proposed`, `Accepted`, `Superseded` y `Rejected`.

- [ADR-0001: TypeScript y arquitectura hexagonal](0001-typescript-hexagonal.md)
- [ADR-0002: local-first y aprobación productiva](0002-local-first-production-approval.md)
- [ADR-0003: excluir DNI/RENIEC de v1](0003-no-dni-v1.md)
- [ADR-0004: cadena de proveedores y procedencia](0004-provider-fallback-and-provenance.md)

Una decisión `Proposed` es la línea de trabajo para los spikes, no permiso para activar producción. Se cambia a `Accepted` cuando se satisfacen las comprobaciones indicadas.
